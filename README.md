## Featured Project

<div align="center">

### Full Stack E-Commerce Application &nbsp;|&nbsp; Spring Boot + Angular

</div>

A complete, production-style **full stack e-commerce web application** built with a **Spring Boot** backend and an **Angular** frontend, demonstrating enterprise-level architecture and secure API design.

**Core Modules**

| Module | Description |
|---|---|
| **User Management** | User registration, login, role-based access, and profile management |
| **Product Management** | CRUD operations for product catalog with search and filtering |
| **Shopping Cart** | Add, update, and remove items with real-time cart state management |
| **Order Management** | Order placement, order history, and order status tracking |

**Key Technical Highlights**

- Secure REST APIs built with **Spring Boot** and **Spring MVC**
- Authentication and authorization powered by **Spring Security** and **JWT**
- Data persistence layer implemented with **Spring Data JPA / Hibernate**
- Relational schema design and query optimization using **MySQL**
- Responsive, component-driven **Angular** frontend with **TypeScript** and **RxJS**
- Clean separation of concerns following a layered, service-oriented architecture
