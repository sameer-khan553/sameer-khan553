<i>"Turning complex business requirements into clean, secure, and scalable full-stack systems — one commit at a time."</i>

I'm **Sameer Khan**, a **Java Full Stack Developer** who designs and builds enterprise-grade web applications end to end — from secure backend services to polished, responsive user interfaces.

On the backend, I engineer RESTful services with **Spring Boot**, **Spring Security**, and **Spring Data JPA**, backed by well-structured **MySQL** schemas via **Hibernate**. On the frontend, I build fast, maintainable interfaces with **Angular**, **TypeScript**, and **RxJS**. ### Full-Stack E-Commerce Platform
**Spring Boot &nbsp;•&nbsp; Angular &nbsp;•&nbsp; MySQL &nbsp;•&nbsp; JWT**

![Spring Boot](https://img.shields.io/badge/Spring%20Boot-6DB33F?style=flat-square&logo=springboot&logoColor=white)
![Angular](https://img.shields.io/badge/Angular-DD0031?style=flat-square&logo=angular&logoColor=white)
![MySQL](https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white)
![JWT](https://img.shields.io/badge/JWT-000000?style=flat-square&logo=jsonwebtokens&logoColor=white)

</div>

A production-style, end-to-end e-commerce application demonstrating enterprise-level architecture, secure authentication, and clean full-stack engineering practices.

<div align="center">

| Module | Description |
|---|---|
| **User Management** | Registration, login, role-based access control, and profile management |
| **Product Management** | Full CRUD for the product catalog, with search and filtering |
| **Shopping Cart** | Real-time cart operations — add, update, and remove items |
| **Order Management** | Order placement, order history, and live status tracking |

</div>

**Engineering Highlights**
- Secure REST APIs designed with **Spring Boot** and **Spring MVC**
- Stateless authentication and authorization via **Spring Security** + **JWT**
- Persistence layer built with **Spring Data JPA / Hibernate**
- Normalized relational schema and query optimization in **MySQL**
- Component-driven, reactive **Angular** frontend using **TypeScript** and **RxJS**
- Clean, layered, service-oriented architecture throughout

To display an animated snake eating your contribution graph, add the following GitHub Actions workflow to this repository at <code>.github/workflows/snake.yml</code>, then reference the generated SVG below.

```yaml
name: Generate Snake
on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches:
      - main
jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        id: snake-gif
        with:
          github_user_name: sameer-khan553
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```
